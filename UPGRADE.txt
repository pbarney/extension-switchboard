Extension Switchboard v0.5.0
============================

New
---
- Export categories and extension assignments as a readable JSON file.
- Import a previously exported configuration.
- Import validates the file before changing the saved configuration.
- Import asks for confirmation and clearly states that extension enabled/disabled
  states will not be changed.
- Exported assignments for extensions not currently installed are preserved.
- Raw configuration objects containing categories and assignments can also be
  imported, in addition to files exported by the switchboard.

UI
--
- rounded button styling.
- Visually separates the "extensions shown" counter in the toolbar.
- Replaced the toolbar icon with a clearer three-switch design.
- Moved Export and Import from the category-management area to the modal header.
- Updated user-facing status terminology:
  - "Active first" -> "Enabled first"
  - "User-disabled first" -> "Disabled first"
  - "Show Firefox-disabled" -> "Show unavailable"
  - Summary now reports "enabled" and "unavailable"
  - Category counts now use "unavailable" instead of "locked"
- Fixed category-list overflow by constraining the category pane and giving the list its own vertical scrollbar.

Storage
-------
- The live configuration remains stored in the Firefox profile preference:
    extensionSwitchboard.config
- Export/import provides portability without changing the live storage model.

Upgrade
-------
Replace the existing profile/chrome/ExtensionSwitchboard.uc.js file with the
this new version, then completely restart Firefox.
