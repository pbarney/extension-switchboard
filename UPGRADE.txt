Extension Switchboard v0.4.0
============================

Upgrade
-------
Replace the existing profile file:

  <Firefox profile>\chrome\ExtensionSwitchboard.uc.js

with ExtensionSwitchboard-v0.4.0.uc.js.txt, removing only the final .txt
suffix. Completely restart Firefox. No changes are required to firefox.cfg or
autoconfig.js.

Changes
-------
- Apply buttons show the number of pending changes.
- Added "Apply and reload tab".
- Apply results list extensions enabled, disabled, and failed.
- Failed changes remain pending and visibly marked for correction or retry.
- Added one-level "Undo last apply" for successfully changed extensions.
- A partial undo retains only failed undo entries so it can be retried.
- New pending selections made after Apply are preserved when Undo runs.
- Undo history lasts for the lifetime of the Firefox browser window and is not
  persisted across a Firefox restart.
