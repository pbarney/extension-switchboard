Extension Switchboard v0.6.0
============================

Internal architecture and maintainability refactor based on v0.5.0.
The user interface, configuration preference, import/export format, and
category schema remain compatible.

Architecture
------------
- FirefoxCompat centralizes Firefox-only APIs and compatibility fallbacks.
- ConfigStore owns preference persistence, sanitization, cloning, and
  import/export validation.
- CategoryManager owns category validation, CRUD, and one-category-per-
  extension assignment rules.
- ExtensionService owns extension enumeration, permission checks, site-access
  classification, and enable/disable operations.
- SwitchboardPanel owns DOM construction, rendering, events, and user feedback.
- SwitchboardController owns startup, toolbar registration, panel lifetime,
  and the one-level undo snapshot.

Cleanup
-------
- Consolidated element creation into shared DOM helpers.
- Moved the complete stylesheet into one versioned style constant and manager.
- Removed the previous monolithic open() closure and separated responsibilities.
- Consolidated configuration rollback behavior for category and import changes.
- Consolidated extension state-changing validation and post-operation checks.

Firefox compatibility retained
------------------------------
- Uses window.Services?.prompt with window.prompt/alert/confirm fallbacks.
- Uses ownerDocument.defaultView to resolve the toolbar button's browser window.
- Retains the working AddonManager and CustomizableUI module import paths.
- Continues creating XHTML elements with createElementNS rather than innerHTML.

Compatibility
-------------
- Existing extensionSwitchboard.config data is used without migration.
- Existing exported JSON files remain importable.
- No changes are required to firefox.cfg or autoconfig.js.

Validation performed
--------------------
- JavaScript syntax check.
- Mocked Firefox startup and toolbar registration.
- Mocked panel construction and extension enumeration.
- Mocked category creation and preference persistence.
- Mocked extension Apply and Undo flows.

Upgrade
-------
Replace the existing profile/chrome/ExtensionSwitchboard.uc.js file with the
contents of ExtensionSwitchboard-v0.6.0.uc.js.txt, removing only the final
.txt suffix, then completely restart Firefox.
